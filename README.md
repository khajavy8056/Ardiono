# پروژه کنترل هوشمند دما و سرعت فن با Arduino Uno

پروژه‌ای کامل، ماژولار و قابل توسعه برای کنترل خودکار سرعت یک فن DC بر
اساس دمای محیط. سیستم بدون هیچ دخالت کاربر کار می‌کند: دما را مداوم
اندازه می‌گیرد، با یک الگوریتم **پیوسته** به سرعت فن نگاشت می‌کند و با
**PWM** سرعت را کنترل می‌کند. تغییرات سرعت به‌تدریج و بدون جهش لحظه‌ای
اعمال می‌شود و در صورت خرابی سنسور، فن به «حالت ایمن» (سرعت کامل)
می‌رود.

---

## ۱. نحوه عملکرد سیستم

1. **اندازه‌گیری پیوسته دما** — هر `SENSOR_SAMPLE_INTERVAL_MS` میلی‌ثانیه
   (پیش‌فرض ۲۰۰۰) یک بار دما خوانده می‌شود.
2. **فیلتر نرم‌افزاری** — نمونه‌ها با یک فیلتر میانگین متحرک نمایی (EMA)
   هموار می‌شوند و نوسان‌های لحظه‌ای سنسور حذف می‌شوند. نمونه‌های مشکوک
   (پرش ناگهانی بزرگ) رد می‌شوند.
3. **نگاشت پیوسته دما به سرعت** — در دماهای کمتر از `TEMP_RAMP_START_C`
   فن در حداقل سرعت است؛ در دماهای بیشتر از `TEMP_RAMP_FULL_C` در
   حداکثر سرعت؛ و بین این دو، سرعت به‌صورت **خطی و پیوسته** بین
   `FAN_MIN_DUTY_PERCENT` و `FAN_MAX_DUTY_PERCENT` محاسبه می‌شود.
   مثلاً با تنظیمات پیش‌فرض (`TEMP_RAMP_START_C=25` ،`TEMP_RAMP_FULL_C=40`
   ،`FAN_MIN=20%` ،`FAN_MAX=100%`):

   | دما (°C) | سرعت فن |
   |----------|---------|
   | ۲۰       | ۲۰٪     |
   | ۲۵       | ۲۰٪     |
   | ۲۸٫۷۵    | ۴۵٪     |
   | ۳۲٫۵     | ۷۰٪     |
   | ۳۶٫۲۵    | ۸۵٪     |
   | ۴۰       | ۱۰۰٪    |
   | ۴۵       | ۱۰۰٪    |

4. **هموارسازی تغییر سرعت** — با `SlewRateLimiter` سرعت فن هر بار حداکثر
   به میزان `FAN_SLEW_RATE_PERCENT_PER_SEC` (درصد بر ثانیه) به هدف نزدیک
   می‌شود؛ بنابراین هیچ جهش ناگهانی در Duty Cycle وجود ندارد.
5. **مدیریت خطا** — اگر `SENSOR_ERROR_THRESHOLD` خواندن پیاپی ناموفق باشد،
   فن بی‌درنگ با **سرعت کامل** کار می‌کند، خطا در Serial Monitor گزارش
   می‌شود و پس از برگشت داده معتبر، کنترل خودکار از سر گرفته می‌شود.
6. **عدم مسدود شدن برنامه** — تمام زمان‌بندی با `millis()` انجام می‌شود و
   هیچ `delay` طولانی در حلقه اصلی وجود ندارد.

### حالت پیش‌فرض (سنسور DHT22 + LCD 16x2)

| قطعه | تعداد | توضیح |
|------|-------|-------|
| Arduino Uno (یا سازگار) | ۱ | برد اصلی |
| سنسور DHT22 (یا DHT11) | ۱ | اندازه‌گیری دما و رطوبت |
| مقاومت ۱۰kΩ | ۱ | پول‌آپ خط داده DHT (اگر ماژول ندارد) |
| فن DC دو سیمه | ۱ | مثلاً ۱۲V DC |
| MOSFET سطح‌منطق (Logic-Level) | ۱ | مثلاً IRLZ44N / IRLZ34N / AO3400 |
| دیود فلایبک | ۱ | 1N4007 یا 1N5819 (شاتکی) |
| مقاومت ۲۲۰Ω تا ۱kΩ | ۱ | محدودکننده جریان گیت MOSFET |
| خازن ۱۰۰µF الکترولیتی + ۱۰۰nF سرامیکی | ۱ هر کدام | فیلتر تغذیه فن |
| منبع تغذیه مناسب فن | ۱ | مثلاً ۱۲V / ۱A (به‌صورت جداگانه!) |
| نمایشگر LCD 16x2 با ماژول I2C | ۱ | اختیاری |
| سیم برد (جامپر) و بردبورد | — | — |

### سایر حالت‌ها

- **سنسور LM35** به جای DHT (سه پایه: VCC / VOUT / GND).
- **نمایشگر OLED 128x64 به‌صورت I2C** به جای LCD.
- **فن چهار سیمه** (قرمز، سیاه، آبی، زرد) به جای فن دو سیمه.

پروژه با کتابخانه‌های زیر کامپایل شده است (فهرست دقیق در

|----------|--------------|--------|

| Adafruit Unified Sensor | 1.1.15 | وابستگی DHT sensor library |
| LiquidCrystal I2C | 1.1.2 | LCD 16x2 با I2C |

### نصب با Arduino IDE

از مسیر **Sketch → Include Library → Manage Libraries…** نام هر کتابخانه
را جست‌وجو و نصب کنید.

### نصب با Arduino CLI

```bash
arduino-cli lib install "DHT sensor library" "Adafruit Unified Sensor" \
    "LiquidCrystal I2C" "Adafruit SSD1306" "Adafruit GFX Library" \
    "Adafruit BusIO"
```

> اگر نمایشگر را غیرفعال کنید (`DISPLAY_TYPE = DISPLAY_NONE`) یا سنسور
> LM35 را انتخاب کنید، کتابخانه‌های غیرضروری اصلاً شناسایی نمی‌شوند و
> نیازی به نصب آن‌ها نیست.

## ۴. نقشه اتصالات

### ۴.۱ سنسور DHT11 / DHT22

```
        +5V ----+-------------------------+
                |                         |
              [10k]                        |
                |                         |
        D2  ----+---------- DATA (DHT)    |
        GND -------------- GND  (DHT)     |
        +5 V -------------- VCC  (DHT)    |
```

| سنسور DHT | Arduino Uno |
|-----------|-------------|
| VCC       | 5V          |
| GND       | GND         |
| DATA      | D2 (`DHT_PIN`) |

اگر سنسور به‌صورت ماژول باشد، معمولاً پول‌آپ داخلی دارد و فقط سه سیم
لازم است.

### ۴.۲ سنسور LM35

```
        +5V ---- VCC (LM35)
        A0  ---- VOUT(LM35)
        GND ---- GND (LM35)
```

| LM35 | Arduino Uno |
|------|-------------|
| VCC  | 5V          |
| VOUT | A0 (`LM35_PIN`) |
| GND  | GND         |

### ۴.۳ فن DC دو سیمه و مدار MOSFET

```
                +12V (منبع جداگانه)
                  |        |
                 [+]      [100µF]
                  |        |
                  +--------+----> مثبت فن
                           |
                          [1N4007]  (دیود فلایبک، به‌صورت معکوس روی فن)
                           |
                  +--------+----> منفی فن
                  |
              D (Drain)
              IRLZ44N        (MOSFET سطح‌منطق)
              S (Source) ---- GND
              G (Gate) ---- [220Ω..1kΩ] ---- D9 (FAN_PWM_PIN)

        GND آردوینو ------------------------------ GND مشترک
```

| اتصال | Arduino Uno / مدار |
|-------|--------------------|
| مثبت فن | +12V منبع تغذیه فن |
| منفی فن | دراین MOSFET |
| سورس MOSFET | GND |
| گیت MOSFET | D9 از طریق مقاومت ۲۲۰Ω تا ۱kΩ |
| دیود فلایبک | موازی با فن (کاتد به +، آند به −) |
| زمین آردوینو | با زمین منبع تغذیه فن **مشترک** شود |

**نکته:** خروجی PWM پیش‌فرض پایه‌های ۹ و ۱۰ حدود ۴۹۰ هرتز است که برای
فن دو سیمه مناسب است.

### ۴.۴ فن DC چهار سیمه (PWM)

فن چهار سیمه چهار سیم دارد:

| رنگ سیم | کاربرد | اتصال |
|---------|--------|-------|
| قرمز   | +12V   | منبع تغذیه فن |
| سیاه   | GND    | GND مشترک با آردوینو |
| آبی    | PWM    | D9 یا D10 (`FAN_PWM_PIN`) |
| زرد    | TACH   | D3 (`FAN4_TACH_PIN`) با پول‌آپ ۱۰kΩ به 5V |

```
        +12V ---- قرمز
        GND  ---- سیاه
        D9   ---- آبی (PWM)
        D3   ----[10k]---+---- زرد (TACH)
                         |
                        +5V
```

**نکته مهم تایمر:** برای رسیدن به فرکانس استاندارد ۲۵kHz، برنامه تایمر ۱
را تغییر می‌دهد. این کار فرکانس PWM پایه‌های ۹ و ۱۰ را تغییر می‌دهد و
با کتابخانه `Servo` (که از تایمر ۱ استفاده می‌کند) ناسازگار است. تابع
`tone()` از تایمر ۲ استفاده می‌کند و تأثیری ندارد.

### ۴.۵ نمایشگر (LCD یا OLED به‌صورت I2C)

هر دو نمایشگر روی یک گذرگاه I2C کار می‌کنند (آدرس‌های متفاوت):

| نمایشگر | Arduino Uno |
|---------|-------------|
| GND     | GND         |
| VCC     | 5V          |
| SDA     | A4          |
| SCL     | A5          |

- آدرس I2C پیش‌فرض LCD: `0x27` (گاهی `0x3F`)
- آدرس I2C پیش‌فرض OLED: `0x3C` (گاهی `0x3D`)

آدرس را در `config.h` می‌توان تغییر داد. اگر آدرس اشتباه باشد، نمایشگر
روشن می‌شود ولی چیزی نشان نمی‌دهد.

## ۵. تنظیمات (`config.h`)

**تنها فایلی که برای شخصی‌سازی پروژه نیاز به ویراشت دارد.**
تمام گزینه‌ها با کامنت فارسی و محدوده مجاز مشخص شده‌اند. 重要ترین گزینه‌ها:

| گزینه | پیش‌فرض | توضیح |
|-------|---------|-------|
| `SENSOR_TYPE` | `SENSOR_DHT22` | نوع سنسور: `SENSOR_DHT11` / `SENSOR_DHT22` / `SENSOR_LM35` |
| `DHT_PIN` | 2 | پایه سنسور DHT |
| `LM35_PIN` | A0 | پایه سنسور LM35 |
| `SENSOR_SAMPLE_INTERVAL_MS` | 2000 | فاصله نمونه‌برداری (ms) |
| `TEMP_FILTER_ENABLED` | 1 | فعال/غیرفعال کردن فیلتر دما |
| `TEMP_FILTER_ALPHA` | 0.30 | ضریب فیلتر EMA (۰ تا ۱) |
| `TEMP_MAX_JUMP_C` | 5.0 | حداکثر پرش مجاز دما (۰ = غیرفعال) |
| `SENSOR_ERROR_THRESHOLD` | 3 | تعداد خطای پیاپی قبل از حالت ایمن |
| `FAILSAFE_DUTY_PERCENT` | 100 | سرعت فن در حالت ایمن |
| `FAN_TYPE` | `FAN_TYPE_DC_2WIRE` | نوع فن: دو سیمه / چهار سیمه |
| `FAN_PWM_PIN` | 9 | پایه PWM فن |
| `FAN4_TACH_PIN` | 3 | پایه تاخ فن چهار سیمه |
| `FAN4_TACH_ENABLED` | 1 | خواندن RPM |
| `FAN4_PWM_FREQUENCY_HZ` | 25000 | فرکانس PWM فن چهار سیمه |
| `FAN_MIN_DUTY_PERCENT` | 20 | حداقل سرعت فن |
| `FAN_MAX_DUTY_PERCENT` | 100 | حداکثر سرعت فن |
| `FAN_ALLOW_STOP` | 0 | اجازه توقف کامل فن در دمای پایین |
| `TEMP_RAMP_START_C` | 25.0 | دمای شروع افزایش سرعت |
| `TEMP_RAMP_FULL_C` | 40.0 | دمای رسیدن به حداکثر سرعت |
| `FAN_SMOOTHING_ENABLED` | 1 | فعال/غیرفعال کردن هموارسازی سرعت |
| `FAN_SLEW_RATE_PERCENT_PER_SEC` | 40.0 | نرخ تغییر سرعت (درصد/ثانیه) |
| `FAN_UPDATE_INTERVAL_MS` | 100 | فاصله به‌روزرسانی سرعت فن |
| `DISPLAY_TYPE` | `DISPLAY_LCD16X2` | `DISPLAY_NONE` / `DISPLAY_LCD16X2` / `DISPLAY_OLED128X64` |
| `LCD_I2C_ADDRESS` | 0x27 | آدرس I2C نمایشگر LCD |
| `OLED_I2C_ADDRESS` | 0x3C | آدرس I2C نمایشگر OLED |
| `DISPLAY_UPDATE_INTERVAL_MS` | 500 | فاصله به‌روزرسانی نمایشگر |
| `SERIAL_ENABLED` | 1 | فعال/غیرفعال کردن گزارش سریال |
| `SERIAL_BAUD` | 9600 | سرعت پورت سریال |
| `SERIAL_REPORT_INTERVAL_MS` | 1000 | فاصله گزارش سریال |

در انتهای `config.h` یک بخش «اعتبارسنجی» وجود دارد که مقادیر نامعتبر
(مثلاً انتخاب هم‌زمان چند سنسور، پایه نامعتبر، تداخل پایه‌ها و محدوده
سرعت) را هنگام کامپایل تشخیص داده و با پیام خطا متوقف می‌کند.

> برای تغییر بازه دمایی کافی است `TEMP_RAMP_START_C` و `TEMP_RAMP_FULL_C`
> را تغییر دهید؛ منطق برنامه بدون هیچ تغییری باقی می‌ماند.

## ۶. روش آپلود برنامه روی Arduino Uno

### با Arduino IDE

1. پوشه `SmartFanController` را باز کنید (فایل `SmartFanController.ino`).
2. در `config.h` تنظیمات موردنظر را انجام دهید.
3. منوی **Tools → Board** را روی «Arduino Uno» بگذارید.
4. منوی **Tools → Port** را روی پورت برد بگذارید.
5. دکمه **Upload** (یا `Ctrl+U`) را بزنید.

### با Arduino CLI

```bash
arduino-cli compile --fqbn arduino:avr:uno ./SmartFanController
arduino-cli upload  --fqbn arduino:avr:uno -p /dev/ttyUSB0 ./SmartFanController
```

## ۷. مشاهده دما و سرعت فن در Serial Monitor

اگر `SERIAL_ENABLED = 1` باشد، برنامه در ابتدای کار یک خلاصه از تنظیمات و
سپس هر ۱۰۰۰ میلی‌ثانیه یک گزارش چاپ می‌کند:

```
=== Smart Fan Controller ===
Sensor : DHT22
Fan    : 2-wire DC (MOSFET)
Display: LCD 16x2 I2C
Ramp   : 25.0C -> 40.0C
Speed  : 20% .. 100%
=============================

T=27.3C H=45% Fan=62% State=AUTO
T=27.5C H=45% Fan=63% State=AUTO
ERROR: sensor read failed (3/3) -> FAILSAFE (fan 100%)
T=27.8C H=46% Fan=100% State=FAILSAFE
Sensor recovered -> AUTO control resumed
T=27.9C H=46% Fan=65% State=AUTO
```

- `T` دما (°C)، `H` رطوبت (٪)، `Fan` درصد سرعت فن، `RPM` سرعت چرخش
  (فقط فن چهار سیمه)، `State` وضعیت سیستم (`AUTO` / `FAILSAFE` / `INIT`).
- سرعت پورت پیش‌فرض ۹۶۰۰ است.

## ۸. راهنمای عیب‌یابی

| مشکل | علت احتمالی | راه‌حل |
|------|-------------|--------|
| فن کاملاً کار نمی‌کند | برد تغذیه فن وصل نیست / MOSFET خراب | اتصالات و قطبیت را بررسی کنید؛ گیت باید به D9 وصل باشد |
| فن دائماً با سرعت کامل کار می‌کند | سنسور داده معتبر نمی‌دهد (حالت ایمن) | اتصال DATA سنسور، پول‌آپ و `DHT_PIN` را بررسی کنید |
| دما در Serial Monitor برابر `nan` است | فاصله نمونه‌برداری کمتر از حداقل DHT است | `SENSOR_SAMPLE_INTERVAL_MS` را به ۲۰۰۰ تغییر دهید |
| نمایشگر روشن است اما خالی است | آدرس I2C اشتباه | آدرس را با اسکنر I2C پیدا و در `config.h` تنظیم کنید |
| نمایشگر اصلاً روشن نمی‌شود | تغذیه I2C وصل نیست | VCC/GND نمایشگر را بررسی کنید |
| فن چهار سیمه صدا می‌کند یا به‌درستی کار نمی‌کند | فرکانس PWM نامناسب | `FAN4_PWM_FREQUENCY_HZ` را روی ۲۵۰۰۰ بگذارید |
| RPM صفر است | سیم تاخ وصل نیست / پول‌آپ لازم است | سیم زرد به D3 و پول‌آپ ۱۰kΩ به 5V |
| خطای کامپایل به صورت `error: ...` در config.h | مقدار نامعتبر در تنظیمات | پیام خطا را بخوانید و مقدار را اصلاح کنید |
| رطوبت درست نیست | — | رطوبت فقط با DHT خوانده می‌شود |

## ۹. تذکرهای ایمنی (مهم)

1. **هرگز فن را مستقیماً از پین ۵V یا ۳٫۳V آردوینو تغذیه نکنید.** جریان فن
   می‌تواند برد یا پورت USB را بسوزاند. از یک **منبع تغذیه جداگانه** با
   ولتاژ و جریان مناسب فن استفاده کنید.
2. **زمین مشترک** بین منبع تغذیه فن و زمین آردوینو ضروری است.
3. برای فن دو سیمه حتماً از **دیود فلایبک** در برابر ولتاژ برگشتی موتور
   استفاده کنید؛ در غیر این صورت MOSFET می‌تواند بسوزد.
4. از **MOSFET سطح‌منطق** (Logic-Level) استفاده کنید تا با ۵ ولت خروجی
   آردوینو به‌درستی سوئیچ شود.
5. یک **مقاومت سری** (۲۲۰Ω تا ۱kΩ) بین پایه آردوینو و گیت MOSFET بگذارید
   و یک **خازن فیلتر** روی تغذیه فن قرار دهید.
6. قبل از برق زدن، اتصالات را دوباره بررسی کنید.

## ۱۱. کامپایل و تست

### نتیجه کامپایل واقعی (با Arduino CLI ،FQBN = `arduino:avr:uno`)

`LiquidCrystal_I2C` است).

### آیا برای تأیید عملکرد واقعی به تست سخت‌افزاری نیاز است؟

**بله، قطعاً.** کامپایل موفق فقط یعنی کد از نظر نحوی و منطقی سازگار است؛
اما تأیید عملکرد فیزیکی (دقت سنسور، درستی مدار MOSFET، رفتار فن،
پایداری در استفاده طولانی‌مدت و بخار) **فقط با اتصال واقعی قطعات و
مشاهده رفتار سیستم** امکان‌پذیر است. هیچ نتیجه‌ای در این مستندات ادعای
تست سخت‌افزاری نمی‌کند.
